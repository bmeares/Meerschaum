## Notes

- Measured on a shared development host that was also running other builds, tests and the CI runner; treat differences under ~20% as noise.
- v5py (the Python facade under MRSM_CORE=rust) is superlinear on sqlite at 1M rows: sync_1M 1106 s and inc_1M 247 s, against 21 s and 3.3 s for the native binary on the same data. The incremental case grows with table size, which points at a per-sync full-table pass in the facade path. Regression: blocks the RC until investigated.
- Chain pipes use v4's default target names: a `{{ Pipe() }}` reference to a pipe with an explicit `target` parameter resolved to the default table name in `mrsm sync pipes` (v5 engine path), failing with `no such table`. v4 resolves it correctly.
- Source tables hold 1 row per second from 2024-01-01 (id = i % 50). Incremental cases add 1% new rows and re-sync with v4's default one-day backtrack.

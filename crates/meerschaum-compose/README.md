# meerschaum-compose

> **Internal crate.** `meerschaum-compose` is an implementation detail of [Meerschaum](https://meerschaum.io)
> and may change in any minor release. Depend on the [`meerschaum`](https://crates.io/crates/meerschaum)
> crate instead.

Meerschaum Compose: the typed model of `mrsm-compose.yaml`, `.env` / envyaml substitution, project resolution and the `compose` subactions.

See the [design document](https://github.com/bmeares/Meerschaum/blob/v5/docs/design/v5.0.0.md) for the crate's place in the workspace.

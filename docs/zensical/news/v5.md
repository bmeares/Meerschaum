# Meet Meerschaum 5

**A new foundation for the same small, useful idea: keep your data flowing.**

!!! info "Documentation preview"
    The final 5.0.0 release is being prepared for review. These examples were checked with the 5.0.0rc16 candidate.

## Start with a Pipe

A query, a file, an API — each can feed a Pipe. Give it a name, sync it, and let incremental updates keep its table current.

[Make your first Pipe →](../get-started/bootstrap.md)

## Connect the steps

Pipelines bring related Pipes together. Preview a plan, run parents before children, and inspect the result of each step. Save the workflow under a name and schedule it when you're ready.

[Build a Pipeline →](../get-started/pipelines.md)

## See what's happening

The console brings Pipes, Pipeline workspaces, jobs, and run history into one place. Teams, permissions, and locks help you share the right controls with the right people.

[Explore the console →](../get-started/start-api.md)

## Keep the tools you like

The Rust core does the heavy lifting. Your Python API, SQL, and `mrsm` commands stay close at hand. New installations return Polars DataFrames; pandas remains a choice. Python plugins can grow into native Rust plugins when you need them.

[Measured performance →](../reference/performance.md) · [Migrating from v4 →](../reference/migrating-to-v5.md)

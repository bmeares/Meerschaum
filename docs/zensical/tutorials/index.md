# Learn by building

Start small, then add one idea at a time. The beginner path uses local SQLite data and works without an external API or database server.

1. [Install and make a workspace](../get-started/index.md).
2. [Build your first Pipe](../get-started/bootstrap.md).
3. [Pick up new rows](../get-started/incremental-sync.md).
4. [Connect a Pipeline](../get-started/pipelines.md).
5. [Explore it in the console](../get-started/start-api.md).
6. [Save it as a project](../get-started/compose-projects.md).

## Choose your next project

| I want to… | Start here |
|---|---|
| Fetch data from my own API or file | [Write a Python plugin](../reference/plugins/writing-plugins.md) |
| Use PostgreSQL, MySQL, or another database | [Add a SQL connector](../reference/connectors/sql-connectors.md) |
| Run transformations when new data arrives | [Continuous Pipelines](../reference/pipelines/continuous.md) |
| Build a native extension | [Write a Rust plugin](../reference/plugins/rust-plugins.md) |
| Give my team a custom page | [Web pages and routes](../reference/plugins/web-pages.md) |

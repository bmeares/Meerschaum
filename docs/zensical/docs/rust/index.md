# Rust

Embed Pipes and the engine in a Rust application, or extend an installed Meerschaum with a native plugin.

| Task | Guide |
|---|---|
| Choose features and dependencies | [Embedding](embedding.md) |
| Write and read rows | [Pipes](pipes.md) |
| Select dependencies and run the engine | [Pipelines](pipelines.md) |
| Add a command or data source | [Plugins](plugins.md) |

Use the public `meerschaum` crate for applications. Use `meerschaum-plugin` for packaged native plugins. The other implementation crates may change between minor releases.

[Complete Rust API reference](https://docs.rs/meerschaum/latest/meerschaum/) · [Plugin SDK](https://docs.rs/meerschaum-plugin/latest/meerschaum_plugin/)
